3) เลือกรอบสำหรับเตือนอุณหภูมิ

ใช้ช่วยจำว่าเครื่องไหนเปิดรับแจ้งเตือน โดย Push ไม่มีข้อมูลผู้ป่วย
วิธีเปิดแจ้งเตือนบนโทรศัพท์
iPhone / iPad
  1. เปิด temp.cnmiblood.com ด้วย Safari
  2. กด Share → “เพิ่มไปยังหน้าจอโฮม”
  3. เปิดจากไอคอน CNMI Temp บนหน้าจอ
  4. เข้าหน้านี้ เลือกประเภทที่ต้องการ แล้วกด “เปิด / บันทึกการแจ้งเตือน”
  5. เมื่อ iPhone ถาม ให้กด “อนุญาต”
Android
  1. เปิด temp.cnmiblood.com ด้วย Chrome
  2. กด “ติดตั้งแอป” หรือ “เพิ่มไปยังหน้าจอหลัก”
  3. เปิด CNMI Temp จากไอคอนแอป
  4. เข้าหน้านี้ เลือกประเภทที่ต้องการ แล้วกด “เปิด / บันทึกการแจ้งเตือน”
  5. เมื่อเครื่องถาม ให้กด “อนุญาต”
ถ้าเคยกดไม่อนุญาต: เปิดสิทธิ์ Notification ของ CNMI Temp ใน Settings แล้วกลับมากดเปิดอีกครั้ง

🚨Incident / BEMติดตามงาน
อุณหภูมิผิดปกติหรือเครื่องมือมีปัญหาจะสร้าง Incident งาน BEM ใช้ BEM Inbox เพื่อรับงาน อัปเดต และเลือก “จบงาน” เพื่อปิดเคส
🔔แจ้งเตือนมือถือเลือกตามเครื่อง
เครื่องเจ้าหน้าที่เลือกพื้นที่/รอบสำหรับเตือนตู้ที่ยังไม่จด ส่วนเครื่อง BEM เปิดรับ Incident และติดตามเคสค้างได้แยกกัน
📡สถานะตู้ / Alarm Testงานคลังเลือด
ใช้เมนู “งานคลังเลือด” สำหรับเปลี่ยนสถานะตู้ บันทึก Alarm Test และค้นประวัติ โดยกรอกชื่อผู้ดำเนินการตามจริงทุกครั้ง
ℹ️ข้อควรรู้ตรวจสอบย้อนหลังได้
ระบบไม่มี Login สำหรับงานทั่วไป จึงต้องระบุชื่อผู้บันทึก/ผู้ดำเนินการจริง ข้อมูล Incident และการแก้ไขเก็บไว้เพื่อ Audit และตรวจย้อนหลัง

เลือกวิธีระบุตู้ → เลือก/พิมพ์/สแกน QR → กรอกอุณหภูมิ → บันทึก

06:00-12:00 เลือกรอบเช้า และ 14:00-21:00 เลือกรอบเย็นให้อัตโนมัติ

ดูย้อนหลัง / Export

เลือกวิธีค้นหาตู้ → เลือกช่วงเวลา → กดแสดงข้อมูล จากนั้น Export CSV ได้

กราฟย้อนหลัง

เลือกรูปแบบค้นหาตู้เหมือนหน้าดูย้อนหลัง → เลือกช่วงเวลา → กดแสดงกราฟ

Incident / BEM

TEMP ผิดช่วงหรือเครื่องมือมีปัญหา ระบบสร้าง Incident และส่ง Google Chat BEM พร้อมลิงก์อัปเดตงาน

เลขงาน BEM

BEM กรอกเลขงานของตัวเองในช่อง “เลขงาน BEM” เพื่อเชื่อมกับ Incident ID ของระบบ

โทรศัพท์

กด “☰ เมนู” เพื่อเปิด Sidebar แล้วกดหัวข้อ ▼ เพื่อกางเมนูย่อย

ติดตั้งเป็นแอป

Android ให้เปิดลิงก์ด้วย Chrome แล้วกด “ติดตั้งแอป” ในเมนู หากเปิดจาก LINE/Google Chat ให้เลือก “เปิดใน Chrome” ก่อน

เปิดการแจ้งเตือน

หลังติดตั้งแอป ให้เข้าเมนู “การแจ้งเตือน” แล้วเลือกว่าจะรับเตือนอุณหภูมิ, Incident BEM หรือทั้งสองแบบ จากนั้นกดเปิดการแจ้งเตือน

KPI และข้อมูลติดตาม

เลือกตัวชี้วัดจาก Dropdown แล้วเลือกเดือน/แผนกเพื่อดูผลอัตโนมัติ ข้อ 1–3 คำนวณจากข้อมูลในระบบ ส่วนข้อ 4 เก็บผลจับเวลาแฟ้มกระดาษเทียบกับแอป แยก 3 แผนก แผนกละ 5 คน และบันทึกทีละคนได้

ตรวจสอบย้อนหลัง

ใช้ “ดูข้อมูลย้อนหลัง”, “กราฟย้อนหลัง” และ “Timeline Incident” เพื่อตรวจประวัติการบันทึกและการดำเนินการ
