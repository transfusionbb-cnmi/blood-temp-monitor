Timeline

คู่มือการใช้งานระบบบันทึกอุณหภูมิ

เปิดอ่านได้ทั้งโทรศัพท์และคอม ใช้งานได้ทันทีโดยไม่ต้อง Login เน้นใช้งานหน้างานจริงแบบเร็ว

จำง่าย ๆ: ระบบเวอร์ชันนี้ไม่มี Login ให้เลือกเมนูที่ต้องใช้ → กรอกข้อมูล → กรอกชื่อผู้บันทึก/ผู้ดำเนินการตามจริงทุกครั้ง

1) เริ่มใช้งานแบบไม่มี Login

  1. เปิดลิงก์ระบบจากโทรศัพท์หรือคอม
  2. เลือกเมนูที่ต้องใช้จาก Sidebar
  3. กรอกชื่อผู้บันทึก/ผู้ดำเนินการตามจริงทุกครั้ง
  4. ถ้าใช้เครื่องร่วมกัน ให้ตรวจชื่อก่อนกดบันทึกหรืออัปเดต

ระบบจะอ้างอิงชื่อที่กรอก วันที่ เวลา และรายละเอียดใน Incident/Timeline แทนบัญชีผู้ใช้

2) บันทึกอุณหภูมิ

  1. เข้าเมนู “บันทึกอุณหภูมิ”
  2. เลือกห้อง/สถานที่เก็บ แล้วเลือกตู้ หรือสแกน QR Code
  3. ระบบเลือก “รอบเช้า” ให้อัตโนมัติช่วง 06:00-12:00 และ “รอบเย็น” ช่วง 14:00-21:00
  4. กรอกอุณหภูมิ ชื่อผู้บันทึก และกดบันทึก

กรณีวัดอุณหภูมิไม่ได้ ให้เลือกเหตุผลและระบุรายละเอียดให้ครบ

3) ดูข้อมูลย้อนหลัง / Export CSV

  1. เข้าเมนู “ดูข้อมูล/Export CSV ย้อนหลัง”
  2. เลือกห้องและตู้ หรือสแกน QR Code
  3. ระบบตั้งค่าเริ่มต้นเป็นข้อมูล 1 เดือนล่าสุด
  4. ข้อมูลแสดงเป็นตารางคล้าย Excel และกด Export CSV ได้

4) กราฟอุณหภูมิย้อนหลัง

  1. เข้าเมนู “กราฟอุณหภูมิย้อนหลัง”
  2. เลือกห้องและตู้ หรือสแกน QR Code
  3. ระบบแสดงกราฟ 1 เดือนล่าสุดเป็นค่าเริ่มต้น
  4. ใช้ดูแนวโน้มก่อนเกิดปัญหา หรือใช้ประกอบการติดตาม Incident

5) เมื่ออุณหภูมิผิดปกติ

  1. ถ้า TEMP ต่ำกว่า min หรือสูงกว่า max ระบบสร้าง Incident
  2. ถ้าวัดไม่ได้เพราะเครื่องมือมีปัญหา/ต้องตาม BEM ระบบส่งเข้าห้อง BEM
  3. BEM กดลิงก์จาก Google Chat เพื่อรับเรื่อง/อัปเดตงาน
  4. ถ้าเป็น “ไม่จดอุณหภูมิ” จะส่งเข้าห้องหน่วยงาน ไม่ส่ง BEM

6) การใช้งานของ BEM

  1. เปิดหมวด “Incident / เครื่องมือแพทย์ (BEM)”
  2. เลือกเมนูตามสถานะ เช่น รอรับเรื่อง, กำลังตรวจสอบ, ส่งซ่อม, ปิดเคส
  3. กรอก “เลขงาน BEM” เพื่อเชื่อมกับระบบงานของ BEM
  4. อัปเดตสถานะและรายละเอียดการดำเนินการทุกครั้ง

เพราะไม่มี Login ให้กรอกชื่อผู้ดำเนินการ เลขงาน BEM และรายละเอียดงานทุกครั้ง

7) เมนูบนโทรศัพท์

  1. กดปุ่ม “☰ เมนู” เพื่อเปิด Sidebar
  2. กดหัวข้อที่มีเครื่องหมาย ▼ เพื่อกางเมนูย่อย
  3. เลือกเมนูที่ต้องใช้ แล้วระบบจะปิดเมนูให้อัตโนมัติ

8) ข้อควรรู้ / การตรวจสอบ

  1. เวอร์ชันนี้ไม่มีหน้า Login และไม่มีการสมัครสมาชิก
  2. ทุกคนต้องกรอกชื่อจริงของผู้บันทึกหรือผู้ดำเนินการเอง
  3. ตรวจสอบประวัติได้จาก “Timeline Incident” และข้อมูลย้อนหลัง
  4. ถ้าต้องปรับ Master ตู้ หรือข้อมูลตั้งต้น ให้ผู้ดูแลระบบดำเนินการผ่านไฟล์/ฐานข้อมูลที่เกี่ยวข้อง
